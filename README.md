# cas-tool

天翼云盘与中国移动云盘(139)的 `.cas` 秒传工具,提供 Web 界面与命令行两种形态,核心逻辑共用。纯 Python 3 标准库实现,无第三方依赖。

**第一次使用请先看 [使用教程](使用教程.md)**:部署、设置、日常操作与常见问题,按步骤照做即可。

## 功能

- **CAS 还原**:天翼版 `.cas` 经 OpenList 种子接口还原至天翼云盘;移动版 `.cas` 直连 139 接口还原至移动云盘;双填版可任选其一。支持批量、多文件压缩包、拖拽上传,还原结果逐项回查确认。
- **CAS 生成**:对两家云盘中的文件流式计算哈希,生成双填版 `.cas`(md5、sliceMd5、sha256 一次算齐),支持多选批量生成;生成结果可逐个下载、批量打包下载、回存至视频同目录,或推送至还原区跨云还原。`.cas` 已保存回原目录的生成任务,可勾选后删除源文件,仅保留 `.cas`;删除前会再次确认同名 `.cas` 仍在源目录。任务区亦可批量删除已保存回原目录的 `.cas` 文件(源文件已删除的任务除外)。
- **CAS 扫描**:独立选项卡,递归扫描指定目录中的 `.cas`,并同步判定原文件在 `.cas` 所在目录中的状态(已存在、同名大小不一致、不存在);扫描结果可推送至还原区统一处理、直接还原至 `.cas` 所在目录(原目录还原将跳过原文件已存在的条目),或批量打包下载。
- **还原失败原因提示**:天翼还原未成功时,自动向 189 服务端查询并显示具体原因,包括文件不存在于云端、秒传请求被拒绝(如文件被列入黑名单,显示服务端返回的原始信息)等。
- **目录管理**:选目录范围限定在设置中配置的挂载目录内,支持在选目录时新建文件夹。
- **移动直连**:移动云盘的浏览、生成、还原、扫描均直连 139 接口,不经过 OpenList;授权临近到期自动刷新,刷新失败可回退至密码登录(支持短信验证)。
- **任务历史**:生成任务记录持久化保存,可查询、选择性清空。

## 部署(Web 界面)

镜像由 GitHub Actions 构建并发布至 GHCR,部署端无需源码与构建步骤:

1. 下载仓库中的 `docker-compose.yml`(内容固定,无需修改),置于 NAS 任意目录。
2. 在该目录执行 `docker compose up -d`,或在群晖 Container Manager 中以项目方式启动。
3. 浏览器打开 `http://NAS地址:8099`,在「设置」页填写各项配置。配置保存在服务端 `data/settings.json`,后续无需再修改 compose 文件。
4. 更新版本:`docker compose pull && docker compose up -d`。

## 配置说明

设置页按云分隔,密钥类字段不回显明文,留空表示不修改:

- **天翼云盘**:接入方式(当前为 OpenList)、OpenList 地址与长期令牌(后台「设置 → 其他 → 令牌」)、挂载目录与额外目录、SessionKey(网页版,用于还原失败时查询原因;获取方式见设置页说明,会过期)。
- **移动云盘**:手机号与授权(Authorization),或从 OpenList 的 139 存储配置中复制 Username、Password、MailCookies 三项以启用密码登录回退;移动云盘目录以「名称 = fileId」形式逐行配置,第一行为默认目录。
- **页面与安全**:访问口令(可选)。全部配置缺失时,亦可通过 compose 环境变量提供初始值。

前置条件:天翼还原依赖 OpenList,且须使用包含种子秒传 sliceMd5 修复的版本(官方 beta 镜像,修复见下方致谢中的 PR #3341);正式版 v4.2.9 不含该修复。

## `.cas` 格式

`.cas` 为 Base64 编码的 JSON,字段为 name、size、md5、sliceMd5、sha256、recover_pass、create_time。两种云盘共用同一容器、填充不同的哈希字段:天翼使用 md5 与 sliceMd5(10MiB 起分片,规则与文件大小相关),移动使用 sha256。因此一份 `.cas` 能否在某家云盘还原,取决于该组哈希是否已填,以及该云盘的服务端是否存在对应文件;两组都填的为双填版。

## 命令行

`cas_tool.py` 提供 inspect(解析判定类型)、gen(本地文件生成)、verify(校验)、restore(按内容自动分流还原)等子命令,凭据仅从环境变量读取,详见 `python3 cas_tool.py -h`。

## 说明

本工具为个人自用项目。移动云盘与天翼云盘的接口均为非官方公开接口,服务端规则变化可能导致部分功能失效;检测与还原结果以各云盘服务端的实际返回为准。
